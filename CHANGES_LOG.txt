  • Problèmes de permissions fichiers
  • Conflits dépendances Python

Solutions fournies (6 variations):
  1. Shallow clone (--depth=1)
     → Clone réduit: ~100 MB au lieu de 500 MB
     
  2. Sparse checkout
     → Télécharger fichiers spécifiques uniquement
     
  3. RUN.sh manuel creation
     → Script launcher custom
     
  4. Disk cleanup commands
     → Libérer espace pour installation
     
  5. Permission fix
     → chmod +x pour exécutables
     
  6. Python environment isolation
     → venv + pip requirements
